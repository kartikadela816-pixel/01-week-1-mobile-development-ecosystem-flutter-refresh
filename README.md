## 4. Jawaban Pertanyaan Refleksi
1. **Pilihan Native vs Flutter**: [Saya memilih Flutter karena dapat digunakan untuk membuat aplikasi pada berbagai platform dengan satu basis kode. Flutter juga memiliki banyak widget yang memudahkan pembuatan tampilan aplikasi serta fitur Hot Reload yang mempercepat proses pengembangan.]
2. **Prinsip UI = f(state)**: [Prinsip UI = f(state) berarti tampilan aplikasi bergantung pada kondisi atau data (state) yang sedang dimiliki. Ketika state berubah, tampilan UI akan menyesuaikan secara otomatis dengan kondisi terbaru.]
3. **Pentingnya Conventional Commits**: [Conventional Commits penting untuk membuat pesan commit lebih terstruktur dan mudah dipahami. Dengan format seperti feat, fix, dan docs, kita dapat mengetahui jenis perubahan yang dilakukan serta mempermudah pengelolaan dan pelacakan project menggunakan Git dan GitHub.]
